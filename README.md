# Jobify Backend API

A RESTful job management API built with **Node.js, Express 5, MongoDB, and Mongoose**.

### Features

- JWT-based user authentication
- Secure password hashing with bcrypt
- CRUD operations for jobs
- User-specific job authorization
- Centralized error handling
- Request validation
- Swagger UI / OpenAPI documentation

### Tech Stack

**Node.js · Express 5 · MongoDB · Mongoose · JWT · bcrypt · Swagger UI**

### Getting Started

```bash
npm install
npm start
````

Create a .env file 

MONGO_URI=mongodb_uri
JWT_SECRET=jwt_secret
JWT_LIFETIME=1d
PORT=3030
